## Теоретические сведения

### 1. Словарь в Python

Словарь (*Dictionary*) — неупорядоченная структура данных, каждый элемент которой является парой «ключ – значение». Ключом может быть любой неизменяемый тип данных (`str`, `int`, `tuple`).

```python
# Создание словаря
d = {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5}
print(d['d'])  # 4

# Добавление и обновление
d['ff'] = 7
d['ff'] = 6

# Удаление
del d['ff']

# Методы
d.update({'f': 6, 'ж': 8})
d.get('b')         # 2
d.pop('b')         # Возвращает 2 и удаляет ключ
d.keys()           # Коллекция ключей
d.values()         # Коллекция значений
d.items()          # Пары (ключ, значение)

# Обход словаря
for key, value in d.items():
    print(key, value)
```

### 2. Сортировка подсчетом (Counting Sort)

Сортировка подсчетом — метод сортировки на основе вспомогательного массива (или словаря), содержащего частоты появления каждого числа из исходного массива.

**Шаги алгоритма:**
1. Определение минимального $q$ и максимального $p$ элемента в массиве.
2. Создание словаря частот с ключами от $q$ до $p$, заполненного нулями.
3. Проход по массиву и инкремент частот.
4. Формирование результирующего массива последовательным разворачиванием элементов по частотам.

*Пример:*  
Исходный массив: `[1, 9, 0, 3, 0, 2, 1, 1, 5, 7, 1, 4, 9]`  
Диапазон: $\min = 0, \max = 9$.  
Частоты: `0: 2, 1: 4, 2: 1, 3: 1, 4: 1, 5: 1, 6: 0, 7: 1, 8: 0, 9: 2`  
Результат: `[0, 0, 1, 1, 1, 1, 2, 3, 4, 5, 7, 9, 9]`

#### Временная сложность:
$$O(n + k)$$
Где $n$ — число элементов, $k$ — диапазон значений ($p - q + 1$).
* При $n = 1024, k = 10 \implies O(n + k) = O(n)$.
* При $n = 100, k = 10000 \implies O(n + k) = O(n^2)$.
