## Solutions & Theoretical Analysis

### Задача № 1. Описание работы функции и таблица стека вызовов

```python
def funct(n):
    if n < 10:
        return n
    else:
        return n % 10 + funct(n // 10)

print(funct(230))
```

Функция возвращает сумму цифр переданного числа. На вход подается целое число `n`:
* Если число однозначное (`n < 10`), срабатывает базовый случай и функция возвращает само число.
* В противном случае выполняется рекурсивный вызов: последняя цифра (`n % 10`) складывается с результатом обработки числа без последней цифры (`n // 10`).

При каждом шаге глубина стека увеличивается, пока не будет достигнута первая цифра числа, после чего начинается возврат значений и их суммирование.

#### Стек вызовов для `funct(230)`:

| № п/п | Имя функции | Переменные и их значения | Возвращаемая команда | Возвращаемое значение |
| :---: | :---: | :---: | :---: | :---: |
| 3 | `funct(n)` | `n = 2` | `return n` | `2` |
| 2 | `funct(n)` | `n = 23` | `return n % 10 + funct(n // 10)` | `3 + funct(2) = 3 + 2 = 5` |
| 1 | `funct(n)` | `n = 230` | `return n % 10 + funct(n // 10)` | `0 + funct(23) = 0 + 5 = 5` |

**Результат работы:** `5`.

### Задача № 2. Описание работы функции и таблица стека вызовов

```python
def funct(k, n):
    if k < n:
        return str(k) + " " + str(funct(k + 1, n))
    else:
        return n

print(funct(4, 12))
```

Функция выводит числовую последовательность от `k` до `n` включительно, разделенную пробелами:
* Пока `k < n`, текущее число переводится в строку и склеивается с пробелом и результатом вызова `funct(k + 1, n)`.
* При `k == n` срабатывает условие останова: возвращается последнее число `n`.

#### Стек вызовов для `funct(4, 12)` (сокращенный фрагмент):

| № п/п | Имя функции | Переменные и их значения | Возвращаемая команда | Возвращаемое значение |
| :---: | :---: | :---: | :---: | :---: |
| 9 | `funct(k, n)` | `k = 12, n = 12` | `return n` | `12` |
| 8 | `funct(k, n)` | `k = 11, n = 12` | `return str(k) + " " + str(funct(k+1, n))` | `"11 12"` |
| ... | ... | ... | ... | ... |
| 2 | `funct(k, n)` | `k = 5, n = 12` | `return str(k) + " " + str(funct(k+1, n))` | `"5 6 7 8 9 10 11 12"` |
| 1 | `funct(k, n)` | `k = 4, n = 12` | `return str(k) + " " + str(funct(k+1, n))` | `"4 5 6 7 8 9 10 11 12"` |

**Результат работы:** `'4 5 6 7 8 9 10 11 12'`.

### Задача № 3. Рекурсивное суммирование списка

Реализованы две функции:
1. `recursive_sum(arr)`: классическое суммирование. Базовый случай — пустой список (возвращает `0`). На каждом шаге берется нулевой элемент `arr[0]` и складывается со срезом `arr[1:]`.
2. `recursive_sum_plus(arr)`: суммирование с фильтрацией отрицательных чисел. Если элемент больше нуля, он прибавляется к сумме, если меньше либо равен нулю — прибавляется `0`.

### Задача № 4. Подсчет нечетных элементов и стек вызовов

* **Итеративный вариант:** обычный цикл `for` с проверкой остатка от деления `x % 2 != 0` и инкрементом счетчика.
* **Рекурсивный вариант:** если список пуст — возвращаем `0`. Иначе прибавляем `1` (если `arr[0]` нечетный) к рекурсивному вызову от оставшейся части списка.

#### Стек вызовов для `count_odd_recursive([5, 8, 11])`:

| № п/п | Имя функции | Входной массив `arr` | Возвращаемая команда | Возвращаемое значение |
| :---: | :---: | :---: | :---: | :---: |
| 4 | `count_odd_recursive` | `[]` | `return 0` | `0` |
| 3 | `count_odd_recursive` | `[11]` | `return 1 + count_odd_recursive([])` | `1 + 0 = 1` |
| 2 | `count_odd_recursive` | `[8, 11]` | `return 0 + count_odd_recursive([11])` | `0 + 1 = 1` |
| 1 | `count_odd_recursive` | `[5, 8, 11]` | `return 1 + count_odd_recursive([8, 11])` | `1 + 1 = 2` |

**Результат работы:** `2` нечетных элемента.

### Задача № 5. Проверка скобочной последовательности (Стек)

#### Словесное описание алгоритма:
1. Заводится пустой список, используемый как стек.
2. Строка читается посимвольно:
   - Если скобка открывающая (`(`, `[`, `{`), она кладется на вершину стека (`push` / `append`).
   - Если скобка закрывающая, проверяется вершина стека: если стек пуст или тип верхней скобки не совпадает с закрывающей — последовательность **некорректна**. При совпадении верхняя скобка извлекается (`pop`).
3. После прохода всей строки: если стек пуст — строка **правильная**, если в стеке остались незакрытые скобки — **неправильная**.

#### Результаты проверки:
* `a) {}[()](())` $\to$ **Корректно** (стек полностью опустошился).
* `б) ()]()()[]` $\to$ **Некорректно** (скобка `]` встретилась при пустом стеке).

### Задача № 6. Минимальное количество скобок для удаления

* **Итеративно:** счетчик баланса `open_count`. Закрывающая скобка без пары увеличивает счетчик удалений. Оставшиеся открытые скобки также идут в удаления.
* **Рекурсивно:** на каждом шаге отрезается первый символ; открытые скобки накапливаются во вспомогательном параметре `open_count`.
* Для строки `(()))(` требуется удалить **2** символа (одну `)` и одну `(`).

### Задачи № 7 и № 8. Восстановление правильной скобочной структуры

Для произвольной строки:
* Все закрывающие скобки, не нашедшие открывающей пары, требуют добавления соответствующих открывающих скобок в самое начало.
* Все открывающие скобки, оставшиеся в стеке, закрываются в обратном порядке в самом конце.

**Пример (Задача № 8):**
* Исходная строка: `()[{](`
* Недостающих скобок: **3**
* Восстановленная строка: `()[{}]()`
