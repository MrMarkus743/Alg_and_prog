## Теоретические сведения

### 1. Рекурсия

#### 1.1. Основные понятия
* **Рекурсия** (от лат. *recursio* — круговорот, возврат) — определение объекта с использованием самого этого объекта.
* **Рекурсия** в программировании — вызов функции самой себя.
* **Рекурсивная функция** — функция, вызывающая сама себя.

Рекурсия является альтернативой циклам. Зачастую код с циклами работает быстрее, чем код с рекурсией. Однако рекурсия в отдельных случаях облегчает написание программы и применяется во многих эффективных алгоритмах.

Знать о рекурсии полезно, так как она позволяет программам обходить структуры, имеющие произвольные и непредсказуемые формы и глубины (например, при планировании маршрутов в путешествии, анализе естественного языка, парсинге DOM/JSON и прохождении по ссылкам в веб-сети).

Рекурсивная функция состоит из **двух обязательных частей**:
1. **Базовый случай (Base case)** — условие, при котором функция прекращает вызывать саму себя, чтобы предотвратить зацикливание (бесконечный вызов).
2. **Рекурсивный случай (Recursive case)** — ветка, в которой функция вызывает саму себя с уменьшающимся набором данных.

##### Листинг 1. Пример функции суммирования элементов списка с использованием рекурсии
```python
def recursive_sum(arr):
    # Базовый случай
    if not arr:
        return 0
    # Рекурсивный случай
    else:
        return arr[0] + recursive_sum(arr[1:])

a = [10, 5, 5, 20]
print(recursive_sum(a))  # Вывод: 40
```

На каждом уровне функция `recursive_sum()` рекурсивно вызывает саму себя для вычисления суммы остатка списка `arr[1:]`, которая затем складывается с первым элементом `arr[0]` (список сокращается на один элемент слева на каждом шаге). Когда список становится пустым (`not arr`), рекурсивный цикл завершается и возвращается `0`.

При использовании такого подхода каждый открытый уровень вызова функции имеет собственную копию локальной области видимости в стеке вызовов времени выполнения (переменная `arr` на каждом уровне разная).

##### Листинг 2. Трассировка промежуточных результатов через print()
```python
def recursive_sum(arr):
    print(arr)  # Трассировка уровней рекурсии
    if not arr:
        return 0
    else:
        return arr[0] + recursive_sum(arr[1:])

a = [10, 5, 5, 20]
print(recursive_sum(a))
```

*Вывод консоли при запуске Листинга 2:*
```text
[10, 5, 5, 20]
[5, 5, 20]
[5, 20]
[20]
[]
40
```

Суммируемый список на каждом уровне становится меньше, пока не опустеет. Сумма вычисляется при «раскручивании» стека вызовов на этапе возврата.

##### Прямая и косвенная рекурсия
Рекурсия может быть:
* **Прямой:** функция вызывает непосредственно себя (как в Листингах 1 и 2).
* **Косвенной (взаимной):** функция вызывает другую функцию, которая, в свою очередь, вызывает первую (Листинг 3).

##### Листинг 3. Пример косвенной рекурсии
```python
def get_sum(arr):
    if not arr:
        return 0
    else:
        return indirect_recursive_sum(arr)

def indirect_recursive_sum(arr):
    return arr[0] + get_sum(arr[1:])  # Косвенная рекурсия

a = [10, 5, 5, 20]
print(get_sum(a))  # Вывод: 40
```

##### Замена рекурсии циклами
Любая рекурсивная функция может быть переписана в итеративной форме с помощью циклов `while` или `for` (Листинг 4).

##### Листинг 4. Использование циклов while и for вместо рекурсии
```python
# Суммирование через цикл while
arr = [10, 5, 5, 20]
sum_ = 0
while arr:
    sum_ += arr[0]
    arr = arr[1:]
print(sum_)

# Суммирование через цикл for
arr = [10, 5, 5, 20]
sum_ = 0
for el in arr:
    sum_ += el
print(sum_)
```

Преимущества использования циклов вместо рекурсии:
1. Не требуется выделять новый блок памяти в стеке вызовов для каждой итерации.
2. Исключаются накладные расходы времени, связанные с организацией вызовов функций в рантайме.

#### 1.2. Обработка произвольных структур
Главное преимущество рекурсии перед циклами — удобство обхода вложенных структур произвольной формы и глубины.  
Например, если список содержит произвольно вложенные подсписки: `[1, [2, [3, 5], 5], 6, [7, 8]]`, то заранее неизвестно, сколько вложенных циклов потребовалось бы написать.

##### Листинг 5. Рекурсивный обход произвольно вложенных списков
```python
def sumtree(L):
    summa = 0
    for x in L:  # Для каждого элемента на текущем уровне
        if not isinstance(x, list):
            summa += x         # Прямое сложение чисел
        else:
            summa += sumtree(x) # Рекурсивный спуск в подсписок
    return summa

L = [1, [2, [3, 4], 5], 6, [7, 8]]
print(sumtree(L))  # Вывод: 36

# Патологические случаи (вложенность с одного края)
print(sumtree([1, [2, [3, [4, [5]]]]]))      # Вывод: 15 (перегруженное справа)
print(sumtree([[[[[1], 2], 3], 4], 5]))      # Вывод: 15 (перегруженное слева)
```

### 2. Стек вызовов (Call Stack)

* **Стек (Stack)** — структура данных, работающая по принципу **LIFO** (*Last In First Out* — последним вошел, первым вышел), аналогично стопке тарелок.
* **Стек вызовов (Call Stack)** — область системной памяти, хранящая контексты активных функций:
  1. При вызове функции ей выделяется фрейм (блок памяти) со всеми локальными переменными.
  2. Если функция вызывает другую функцию, новый блок кладется на вершину стека, а выполнение предыдущей приостанавливается.
  3. По завершении вложенной функции её блок удаляется из стека, а управление возвращается к вызывающей функции.

#### Хвостовая рекурсия (Tail Recursion)
Хвостовая рекурсия — частный случай рекурсии, где рекурсивный вызов является самым последним действием перед возвратом. Накопленный результат передается через дополнительный аргумент-аккумулятор:

```python
# Обычная рекурсия (требует сохранения состояния для сложения после возврата)
def recsum(x):
    if x == 1:
        return x
    else:
        return x + recsum(x - 1)

# Хвостовая рекурсия (накапливает результат в running_total)
def tailrecsum(x, running_total=0):
    if x == 0:
        return running_total
    else:
        return tailrecsum(x - 1, running_total + x)
```

### 3. Рекурсия и стек

Стандартный Python ограничивает максимальную глубину стека вызовов во избежание переполнения памяти при бесконечной рекурсии. Просмотр и изменение лимита производятся через модуль `sys` (Листинг 6):

##### Листинг 6. Управление глубиной стека через sys
```python
import sys

print(sys.getrecursionlimit())      # Просмотр лимита (по умолчанию 1000 или 3000)
sys.setrecursionlimit(10000)         # Установка нового лимита
help(sys.setrecursionlimit)          # Справка по методу
```
