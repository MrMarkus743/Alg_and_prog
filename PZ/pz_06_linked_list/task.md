## Теоретические сведения

### 1. Структуры данных: массив, связный список

#### 1.1. Память компьютера
При сохранении отдельного значения в памяти используется адрес ячейки. Сохранение нескольких элементов реализуется двумя принципиальными способами:
1. **Массив**;
2. **Связный список**.

* **Структура данных (Data Structure)** — способ (формат) хранения данных для их эффективного поиска и извлечения.
* **Тип доступа:**
  - **Последовательный:** элементы читаются строго по одному начиная с первого.
  - **Произвольный:** прямой доступ к элементу по индексу/адресу.

#### 1.2. Массив
* Все элементы хранятся в памяти непрерывно (друг за другом).
* Тип доступа: произвольный ($O(1)$ по индексу).
* **Недостатки:** неэффективный расход памяти при выделении ячеек «про запас»; ресурсозатратное копирование в новую область памяти при переполнении.

#### 1.3. Связный список
* Элементы (узлы) хранятся в памяти разрозненно. Каждый узел хранит само значение и указатель на следующий элемент.
* Тип доступа: последовательный.
* **Недостатки:** затруднен доступ к произвольному элементу (требуется проход с головы списка $O(n)$).
* **Преимущества:** эффективная вставка и удаление в начале или середине списка без сдвига остальных элементов.

```text
Array:       [ ● | ● | ● | ● | ● |   ]  (непрерывный блок в RAM)

Linked List: (●) ---> (●) ---> (●) ---> (●) ---> (●)  (разрозненные узлы)
```

#### Топологии связных списков:
1. **Однонаправленный (Single Linked List):** связь только вперед (`link_next`).
2. **Двунаправленный (Doubly Linked List):** связи вперед (`link_next`) и назад (`link_prev`).
3. **Циклический (Circular Linked List):** последний узел замыкается ссылкой на первый (`head`).

---

#### 1.4. Операции со структурами данных

#### Таблица 1. Сложность основных операций над массивом и связным списком

| Структура данных | Поиск (чтение) | Вставка | Удаление |
| :--- | :---: | :---: | :---: |
| **Массив** | $O(1)$ | $O(n)$ | $O(n)$ |
| **Связный список** | $O(n)$ | $O(1)^*$ | $O(1)^*$ |

*\* Операции вставки и удаления в связном списке занимают $O(1)$, если ссылка на искомый узел уже получена.*

### 2. Реализация однонаправленного связного списка на Python

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.link_next = None

class SinglyLinkedList:
    def __init__(self):
        self.head = None

    def appendToTail(self, value):
        node_end = Node(value)
        if self.head is None:
            self.head = node_end
            return
        link_current = self.head
        while link_current.link_next is not None:
            link_current = link_current.link_next
        link_current.link_next = node_end
```
