## Теоретические сведения

### 1. Очередь: общие сведения

* **Очередь (Queue)** — структура данных, работающая по принципу **FIFO** (*First In First Out* — первым вошел, первым вышел), аналогично трубке с шариками (первый вошедший шарик выходит первым).
* Очередь, так же, как и стек, **не поддерживает обращение к произвольному элементу**.
* **Основные операции очереди:**
  - `Enqueue` — постановка в очередь (в конец).
  - `Dequeue` — извлечение из очереди (с начала).

```text
Вход (Enqueue) ---> [ Хвост | ... | ... | Голова ] ---> Выход (Dequeue)
```

* **Дек (Deque, Double-ended queue)** — особый тип очереди, двусторонняя очередь. Отличается тем, что операции добавления и извлечения могут происходить с обоих концов.
* **Операции дека:**
  - `Enqueue` — постановка в очередь (в конец).
  - `Dequeue` — извлечение из очереди (с начала).
  - `Front` — постановка в очередь (в начало).
  - `Rear` — извлечение из очереди (с конца).

### 2. Реализация очереди в Python

Очередь может быть реализована на Python следующими способами:
1. Встроенный список (`list`).
2. Класс `collections.deque`.
3. Класс `queue.Queue`.
4. Класс `multiprocessing.Queue`.

---

#### 2.1. Встроенный список (list)

Используются следующие методы и операции:
* `= []` — создание пустой очереди;
* `.append(x)` — постановка в очередь (в конец);
* `.pop(0)` — извлечение из очереди (извлекается нулевой элемент);
* `.insert(0, x)` — постановка в начало очереди;
* `.pop()` или `.pop(-1)` — извлечение с конца очереди;
* `len(q)` — определение текущего размера;
* `q.clear()` — очистка очереди.

##### Таблица операций над списком (list):

| Имя операции | Команда | Пример вызова | Содержимое очереди |
| :--- | :--- | :--- | :--- |
| **Создание пустой очереди** | `= []` | `q = []` | `[]` |
| **Постановка в очередь** | `.append()` | `q.append(1)`<br>`q.append(2)`<br>`q.append(3)` | `[1]`<br>`[1, 2]`<br>`[1, 2, 3]` |
| **Извлечение из очереди** | `.pop(0)` | `q.pop(0)`<br>`q.pop(0)`<br>`q.pop(0)` | `[2, 3]`<br>`[3]`<br>`[]` |
| **Постановка в начало** | `.insert(0, x)` | `q.insert(0, 3)`<br>`q.insert(0, 2)`<br>`q.insert(0, 1)` | `[3]`<br>`[2, 3]`<br>`[1, 2, 3]` |
| **Извлечение с конца** | `.pop()` | `q.pop()`<br>`q.pop()` | `[1, 2]`<br>`[1]` |

> **Недостаток встроенного списка:** низкая производительность. Удаление первого элемента (`pop(0)`) или вставка на первую позицию (`insert(0, x)`) требуют сдвига всех последующих элементов в памяти, что занимает **$O(n)$** времени. Использовать `list` для очередей с большим числом элементов не рекомендуется.

#### 2.2. Класс collections.deque

Класс `deque` встроенной библиотеки `collections` оптимизирован по памяти и поддерживает операции добавления и извлечения с обоих концов с асимптотической сложностью **$O(1)$**:

```python
from collections import deque
```

##### Таблица операций над collections.deque:

| Имя операции | Команда | Пример вызова | Содержимое дека |
| :--- | :--- | :--- | :--- |
| **Создание пустого дека** | `deque()` | `q = deque()` | `deque([])` |
| **Постановка в конец** | `.append()` | `q.append(1)`<br>`q.append(2)` | `deque([1])`<br>`deque([1, 2])` |
| **Извлечение из начала** | `.popleft()` | `q.popleft()` | `deque([2])` |
| **Постановка в начало** | `.appendleft()`| `q.appendleft(0)` | `deque([0, 2])` |
| **Извлечение с конца** | `.pop()` | `q.pop()` | `deque([0])` |

*Дополнительные операции:* `len(q)` — определение длины, `q.clear()` — полная очистка.

---

#### 2.3. Класс queue.Queue

Библиотека `queue` предоставляет потокобезопасные очереди для многопоточного программирования:

```python
from queue import Queue, LifoQueue
```

##### Таблица операций над queue.Queue:

| Имя операции | Команда | Пример вызова | Содержимое очереди |
| :--- | :--- | :--- | :--- |
| **Создание очереди** | `Queue()` | `q = Queue()` | Внутренний контейнер |
| **Постановка в очередь** | `.put()` | `q.put(1)`<br>`q.put(2)` | Добавлено в хвост |
| **Извлечение из очереди** | `.get()` | `val = q.get()` | Возвращает элемент |

* Стек реализуется через класс `queue.LifoQueue`.
* Дополнительные методы: `q.qsize()` — размер, `q.empty()` — проверка на пустоту.
* Просмотр содержимого через `q.queue` возвращает внутренний `deque`, но прямая модификация этого объекта является небезопасной.

## Задачи для выполнения

> **Важное методическое правило:** при выполнении задач **не допускается** обращение к произвольному элементу стека или очереди по индексу (`s[i]`, `q[i]`). Используются строго регламентированные методы интерфейса!

### Задача № 1
Дано число $N > 0$ и набор из $N$ чисел. Создать стек, содержащий исходные числа (последнее число будет вершиной стека). Извлечь из стека все элементы и вывести их значения. Вывести также количество извлеченных элементов $N$.  
*Стек необходимо реализовать, используя:*
1. Встроенный список (`list`);
2. Класс `collections.deque`;
3. Класс `queue.LifoQueue`.

### Задача № 2
Даны два непустых стека. Переместить все элементы из первого стека во второй (в результате элементы первого стека будут располагаться во втором стеке в порядке, обратном исходному).

### Задача № 3
Дан один непустой стек. Создать два новых стека, переместив в первый из них все элементы исходного стека с четными значениями, а во второй — с нечетными (элементы в новых стеках будут располагаться в порядке, обратном исходному; один из этих стеков может оказаться пустым).  
*Стек необходимо реализовать, используя:*
1. Класс `collections.deque`;
2. Класс `queue.LifoQueue`.

### Задача № 4
Дан набор из $N$ чисел ($N > 10$). Создать очередь, содержащую данные числа в указанном порядке (первое число будет размещаться в начале очереди, последнее — в конце). Извлечь из очереди все элементы и вывести их значения. Вывести также количество извлеченных элементов $N$.  
*Очередь необходимо реализовать, используя:*
1. Встроенный список (`list`);
2. Класс `collections.deque`;
3. Класс `queue.Queue`.

### Задача № 5
Дан набор из 10 чисел. Создать две очереди: первая должна содержать числа из исходного набора с нечетными порядковыми номерами (индексами), а вторая — с четными; порядок чисел в каждой очереди должен совпадать с порядком чисел в исходном наборе.

### Задача № 6
Дан набор из 10 чисел. Создать две очереди: первая должна содержать все нечетные, а вторая — все четные числа из исходного набора (порядок чисел в каждой очереди должен совпадать с порядком чисел в исходном наборе).

### Задача № 7
Дано число $D$ и очередь, содержащая не менее 10 элементов. Добавить элемент со значением $D$ в конец очереди и извлечь из очереди первый (начальный) элемент. Вывести значение извлеченного элемента.

### Задача № 8
Дано число $N > 0$ и непустая очередь. Создать функцию для извлечения из очереди $N$ начальных элементов и отображения их значений (если очередь содержит менее $N$ элементов, то извлечь все ее элементы).

### Задача № 9
Дана непустая очередь. Извлекать из очереди элементы, пока значение начального элемента очереди не станет четным, и выводить значения извлеченных элементов (если очередь не содержит элементов с четными значениями, то извлечь все ее элементы).

### Задача № 10
Даны две очереди. Переместить все элементы первой очереди (в порядке от начала к концу) в конец второй очереди.

### Задача № 11
Дано число $N > 0$ и две непустые очереди. Создать функцию для перемещения $N$ начальных элементов первой очереди в конец второй очереди. Если первая очередь содержит менее $N$ элементов, то переместить из первой очереди во вторую все элементы.  
*Очередь необходимо реализовать, используя:*
1. Класс `collections.deque`;
2. Класс `queue.Queue`.

### Задача № 12
Даны две непустые очереди. Очереди содержат одинаковое количество элементов. Объединить очереди в одну, в которой элементы исходных очередей чередуются (начиная с первого элемента первой очереди).

### Задача № 13
Даны две непустые очереди. Элементы каждой из очередей упорядочены по возрастанию (в направлении от начала очереди к концу). Объединить очереди в одну с сохранением упорядоченности элементов.  
*Очередь необходимо реализовать, используя:*
1. Класс `collections.deque`;
