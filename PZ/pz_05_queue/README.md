# Practical Work 05: Queue and Deque Data Structures

## Overview

Практическая работа посвящена исследованию структур данных Очередь (FIFO) и Дек (двусторонняя очередь). Рассмотрены три варианта их реализации на языке Python: встроенный динамический список `list`, оптимизированный двусвязный список блоков `collections.deque` и потокобезопасный класс `queue.Queue`. Выполнены задачи на перемещение, фильтрацию, чередование и слияние очередей без произвольного доступа по индексу.

---

## Solutions & Theoretical Analysis

### 1. Сравнение подходов к реализации очереди в Python

| Структура | Вставка в конец | Извлечение из начала | Расход памяти | Где использовать |
| :--- | :---: | :---: | :---: | :--- |
| **`list`** | $O(1)$ аморт. | $O(n)$ | Минимальный | Не подходит для больших очередей из-за сдвига памяти |
| **`collections.deque`** | $O(1)$ | $O(1)$ | Низкий | Оптимальный выбор для алгоритмов и очередей в одном потоке |
| **`queue.Queue`** | $O(1)$ | $O(1)$ | Средний | Многопоточные программы (защита от гонок данных через Lock) |

> **Главный вывод:** Удаление первого элемента из обычного списка `list.pop(0)` физически сдвигает все оставшиеся $n-1$ ссылок в памяти на один шаг влево, что дает квадратичную задержку при обработке потока данных. Класс `deque` работает за гарантированные $O(1)$ с обоих концов.

### 2. Разбор решений практических задач

#### Задачи № 1–3: Структура данных Стек (LIFO)
* **Задача 1:** Набор из $N$ чисел загружается в стек и полностью извлекается. Из-за принципа LIFO (последний пришел — первый ушел) порядок вывода оказывается обратным исходному. Реализовано на `list`, `deque` и `queue.LifoQueue`.
* **Задача 2:** Перенос из первого стека во второй осуществляется последовательным снятием с вершины `stack2.append(stack1.pop())`. В результате элементы во втором стеке переворачиваются.
* **Задача 3:** Элементы исходного стека вынимаются и раскладываются по четности (`val % 2 == 0`) в два независимых стека `even_stack` и `odd_stack`.

#### Задачи № 4–6: Базовые очереди и фильтрация (FIFO)
* **Задача 4:** Набор из $N$ чисел ($N > 10$) проходит через очередь. Элементы выходят строго в том порядке, в котором поступили (FIFO).
* **Задача 5:** Разделение по четности индекса входного набора: элементы с нечетными номерами направляются в `q_odd_idx`, с четными — в `q_even_idx`.
* **Задача 6:** Разделение по четности значений чисел набора в две независимые очереди `q_odd` и `q_even`.

#### Задачи № 7–9: Извлечение и модификация на лету
* **Задача 7:** Число $D$ ставится в хвост очереди (`append`), после чего начальный элемент извлекается (`popleft`). Сложность операции — строго $O(1)$.
* **Задача 8:** Функция `task_8(q, n)` извлекает до $N$ первых элементов очереди в цикле `while len(q) > 0 and count < n`, безопасно завершаясь, если в очереди меньше $N$ элементов.
* **Задача 9:** Извлечение элементов продолжается до тех пор, пока извлеченное значение не станет четным (`val % 2 == 0`), после чего цикл прерывается.

#### Задачи № 10–13: Операции над несколькими очередями
* **Задача 10:** Все элементы первой очереди один за другим перекладываются в конец второй: `q2.append(q1.popleft())`. Исходный порядок сохраняется.
* **Задача 11:** Перенос ровно $N$ элементов из начала первой очереди в конец второй (с проверкой на исчерпание элементов первой очереди).
* **Задача 12:** Чередование двух очередей равной длины: на каждом шаге цикла извлекается один элемент из `q1` и один элемент из `q2`, формируя общую объединенную очередь: `[q1_0, q2_0, q1_1, q2_1, ...]`.
* **Задача 13:** Слияние двух очередей, элементы которых уже упорядочены по возрастанию. Алгоритм сравнивает головы очередей, выбирает меньшее значение и помещает в результирующую очередь (аналог фазы слияния Merge Sort). Время выполнения — линейное $O(n_1 + n_2)$, без повторных сортировок массива.
