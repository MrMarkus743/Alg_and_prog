## Теоретические сведения

### 1. Алгоритмы сортировки

Многие эффективные алгоритмы поиска (например, бинарный поиск) требуют строго упорядоченных данных. **Сортировка** — это процесс преобразования последовательности элементов путем их перестановки для упорядочивания по определенному критерию (по возрастанию или убыванию).

#### Сводная таблица сложности основных алгоритмов сортировки

| Алгоритм | Время: Лучшее | Время: Среднее | Время: Худшее | Память (Worst) |
| :--- | :---: | :---: | :---: | :---: |
| **Quicksort** | $\Omega(n \log n)$ | $\Theta(n \log n)$ | $O(n^2)$ | $O(\log n)$ |
| **Mergesort** | $\Omega(n \log n)$ | $\Theta(n \log n)$ | $O(n \log n)$ | $O(n)$ |
| **Timsort** | $\Omega(n)$ | $\Theta(n \log n)$ | $O(n \log n)$ | $O(n)$ |
| **Heapsort** | $\Omega(n \log n)$ | $\Theta(n \log n)$ | $O(n \log n)$ | $O(1)$ |
| **Bubble Sort** | $\Omega(n)$ | $\Theta(n^2)$ | $O(n^2)$ | $O(1)$ |
| **Insertion Sort** | $\Omega(n)$ | $\Theta(n^2)$ | $O(n^2)$ | $O(1)$ |
| **Selection Sort**| $\Omega(n^2)$ | $\Theta(n^2)$ | $O(n^2)$ | $O(1)$ |
| **Tree Sort** | $\Omega(n \log n)$ | $\Theta(n \log n)$ | $O(n^2)$ | $O(n)$ |
| **Shell Sort** | $\Omega(n \log n)$ | $\Theta(n(\log n)^2)$| $O(n(\log n)^2)$ | $O(1)$ |
| **Bucket Sort** | $\Omega(n+k)$ | $\Theta(n+k)$ | $O(n^2)$ | $O(n)$ |
| **Radix Sort** | $\Omega(nk)$ | $\Theta(nk)$ | $O(nk)$ | $O(n+k)$ |
| **Counting Sort**| $\Omega(n+k)$ | $\Theta(n+k)$ | $O(n+k)$ | $O(k)$ |
| **Cubesort** | $\Omega(n)$ | $\Theta(n \log n)$ | $O(n \log n)$ | $O(n)$ |

### 1.1. Сортировка выбором

**Сортировка выбором (Selection Sort)** — алгоритм, при котором $n$ раз выполняется поиск минимального значения в неотсортированной части массива и его перенос в отсортированную позицию.

Исходный массив: `[5, 3, 30, 2, 88, 42, 17, 16]`

#### Вариант А: Реализация через 2 массива
Минимальный элемент извлекается из исходного массива и переносится в конец вспомогательного:
* **Шаг 1:** `min = 2`  $\to$ Новый массив: `[2]`
* **Шаг 2:** `min = 3`  $\to$ Новый массив: `[2, 3]`
* **Шаг 3:** `min = 5`  $\to$ Новый массив: `[2, 3, 5]`
* **Шаг 4:** `min = 16` $\to$ Новый массив: `[2, 3, 5, 16]`
* **Шаг 5:** `min = 17` $\to$ Новый массив: `[2, 3, 5, 16, 17]`
* **Шаг 6:** `min = 30` $\to$ Новый массив: `[2, 3, 5, 16, 17, 30]`
* **Шаг 7:** `min = 42` $\to$ Новый массив: `[2, 3, 5, 16, 17, 30, 42]`
* **Шаг 8:** `min = 88` $\to$ Новый массив: `[2, 3, 5, 16, 17, 30, 42, 88]`

#### Вариант Б: Реализация «на месте» (In-Place, через 1 массив)
Обмен значениями между первым элементом рабочего диапазона и найденным минимальным:

```text
Шаг 1: [ 5,  3, 30, (2), 88, 42, 17, 16] -> меняем 5 и 2  -> [ 2 |  3, 30,  5, 88, 42, 17, 16]
Шаг 2: [ 2 | (3), 30,  5, 88, 42, 17, 16] -> мин на месте -> [ 2,  3 | 30,  5, 88, 42, 17, 16]
Шаг 3: [ 2,  3 | 30, (5), 88, 42, 17, 16] -> меняем 30 и 5 -> [ 2,  3,  5 | 30, 88, 42, 17, 16]
Шаг 4: [ 2,  3,  5 | 30, 88, 42, 17, (16)]-> меняем 30 и 16-> [ 2,  3,  5, 16 | 88, 42, 17, 30]
Шаг 5: [ 2,  3,  5, 16 | 88, 42, (17), 30]-> меняем 88 и 17-> [ 2,  3,  5, 16, 17 | 42, 88, 30]
Шаг 6: [ 2,  3,  5, 16, 17 | 42, 88, (30)]-> меняем 42 и 30-> [ 2,  3,  5, 16, 17, 30 | 88, 42]
Шаг 7: [ 2,  3,  5, 16, 17, 30 | 88, (42)]-> меняем 88 и 42-> [ 2,  3,  5, 16, 17, 30, 42 | 88]
Шаг 8: [ 2,  3,  5, 16, 17, 30, 42, 88 ] (Отсортировано)
```
* **Сложность по времени:** $O(n^2)$ во всех случаях (лучший, средний, худший).

### 1.2. Сортировка пузырьком

**Сортировка пузырьком (Bubble Sort)** — алгоритм, основанный на последовательном попарном сравнении соседних элементов слева направо и их обмене, если левый элемент больше правого. В результате каждого полного прохода самое «тяжелое» (максимальное) значение всплывает в крайнюю правую позицию.

Количество внешних проходов равно $n - 1$:
* **Проход 1:** Наибольшее число `88` смещается в позицию `index 7`.
* **Проход 2:** Число `42` смещается в позицию `index 6`.
* **Проход 3:** Число `30` смещается в позицию `index 5`.
* **Проходы 4–7:** Оставшиеся малые элементы последовательно упорядочиваются.

* **Временная сложность:**
  - Лучший случай: $O(n)$ (при наличии флага досрочного выхода, если массив уже отсортирован).
  - Средний и худший случай: $O(n^2)$.

#### Сравнение алгоритмов поиска и сортировки

| Алгоритм | Лучший случай | Средний случай | Худший случай |
| :--- | :---: | :---: | :---: |
| **Линейный поиск** | $O(1)$ | $O(n)$ | $O(n)$ |
| **Бинарный поиск** | $O(1)$ | $O(\log n)$ | $O(\log n)$ |
| **Сортировка выбором** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ |
| **Сортировка пузырьком** | $O(n)$ | $O(n^2)$ | $O(n^2)$ |

## 2. Сложность операций со структурами данных

### 2.1. Сложность операций с массивом
* **Массив (Array)** — непрерывная область памяти, хранящая элементы одного типа с прямым доступом по целочисленному индексу ($O(1)$).
* При вставке или удалении элементов в середину или начало массива требуется физический сдвиг всех последующих элементов, что занимает $O(n)$ времени.

| Структура | Поиск (чтение по индексу) | Вставка элемента | Удаление элемента |
| :--- | :---: | :---: | :---: |
| **Массив** | $O(1)$ | $O(n)$ | $O(n)$ |

### 2.2. Сложность операций со списком и кортежем в Python
Список Python (`list`) внутри CPython реализован как динамический массив указателей (ссылок) на объекты.

| Операция | Сложность | Примечание |
| :--- | :---: | :--- |
| `len(lst)` | $O(1)$ | Длина хранится в метаданных структуры |
| `lst.append(x)` | $O(1)$ | Амортизированная константа (динамическое расширение) |
| `lst.pop()` | $O(1)$ | Удаление последнего элемента (`pop(-1)`) |
| `lst.clear()` | $O(1)$ | Аналогично переназначению `lst = []` |
| `lst[a:b]` | $O(b - a)$ | Зависит от размера формируемого среза |
| `lst.extend(...)` | $O(\text{len}(\dots))$ | Зависит от размера добавляемой коллекции |
| `list(...)` | $O(\text{len}(\dots))$ | Создание нового списка из итерируемого объекта |
| `lst1 == lst2` | $O(n)$ | Поэлементное сравнение |
| `lst[a:b] = ...` | $O(n)$ | Вставка среза со сдвигом элементов |
| `del lst[i]` | $O(n)$ | Сдвиг всех элементов правее индекса $i$ |
| `lst.remove(x)` | $O(n)$ | Поиск значения $O(n)$ + удаление со сдвигом $O(n)$ |
| `x in lst` | $O(n)$ | Линейный поиск по элементам |
| `lst.copy()` | $O(n)$ | Поверхностное копирование ссылок |
| `lst.pop(i)` | $O(n)$ | Удаление из произвольного места со сдвигом |
| `min(lst)` / `max(lst)` | $O(n)$ | Полный проход по массиву |
| `lst.reverse()` | $O(n)$ | Разворот массива на месте |
| `for v in lst:` | $O(n)$ | Полный перебор элементов |
| `lst.sort()` | $O(n \log n)$ | Алгоритм Timsort |
| `k * lst` | $O(k \cdot n)$ | Размножение элементов списка |

## 3. Оценка сложности совокупности алгоритмов по О-нотации

### 3.1. Закон сложения
Итоговая сложность последовательно выполняемых шагов равна сумме их сложностей:
$$O(f(n)) + O(g(n)) = O(f(n) + g(n))$$

**Правила вычисления:**
1. Доминирование старшего слагаемого: $O(n) + O(\log n) = O(n)$.
2. Отбрасывание константных множителей: $O(N) + O(N) + O(N) = 3 \cdot O(N) \to O(N)$.
3. При ветвлении (`if-else`) учитывается худшая ветка исполнения:
   ```python
   if test:      # O(t)
       block_1   # O(b1)
   else:
       block_2   # O(b2)
   # Итоговая сложность: O(t) + max(O(b1), O(b2))
   ```

### 3.2. Закон умножения
Итоговая сложность вложенных инструкций равна произведению их сложностей:
$$O(f(n)) \times O(g(n)) = O(f(n) \cdot g(n))$$

Пример вложенных циклов:
```python
for i in range(N):       # O(N)
    for j in range(N):   # O(N)
        pass             # O(1)
# Общая сложность: O(N * N) = O(N^2)
```

#### Пример комплексного анализа (Листинг 1):
```python
def is_unique_1(data):
    """Возвращает True, если все элементы коллекции data уникальны."""
    for i in range(len(data)):           # Внешний цикл: O(N)
        if data[i] in data[i + 1:]:      # Срез O(N) + оператор in O(N) -> O(N)
            return False                 # O(1)
    return True                          # O(1)
# Итоговая сложность программы: O(N) * O(N) = O(N^2)
```

## Методические указания

### Пошаговый разбор сортировки пузырьком для списка `[6, 12, 4, 3, 8]`

* **Итерация 1:** Число `12` всплывает в конец (4 сравнения):
  - $6 > 12$ (Нет) $\to [6, 12, 4, 3, 8]$
  - $12 > 4$ (Да, меняем) $\to [6, 4, 12, 3, 8]$
  - $12 > 3$ (Да, меняем) $\to [6, 4, 3, 12, 8]$
  - $12 > 8$ (Да, меняем) $\to [6, 4, 3, 8, 12]$
* **Итерация 2:** Число `8` занимает позицию перед `12` (3 сравнения):
  - $6 > 4$ (Да, меняем) $\to [4, 6, 3, 8, 12]$
  - $6 > 3$ (Да, меняем) $\to [4, 3, 6, 8, 12]$
  - $6 > 8$ (Нет) $\to [4, 3, 6, 8, 12]$
* **Итерация 3:** (2 сравнения):
  - $4 > 3$ (Да, меняем) $\to [3, 4, 6, 8, 12]$
  - $4 > 6$ (Нет) $\to [3, 4, 6, 8, 12]$
* **Итерация 4:** (1 сравнение):
  - $3 > 4$ (Нет) $\to [3, 4, 6, 8, 12]$ — массив отсортирован.

### Базовые реализации алгоритмов

#### Сортировка выбором через 2 массива:
```python
a = [6, 12, 4, 3, 8]
a_old = a.copy()
a_sort = []
n = len(a_old)

for i in range(n):
    cur_len = len(a_old)
    min_value = a_old[0]
    min_value_idx = 0
    for j in range(1, cur_len):
        if a_old[j] < min_value:
            min_value = a_old[j]
            min_value_idx = j
            
    a_sort.append(min_value)
    a_old.pop(min_value_idx)

print("Отсортированный массив:", a_sort)
```

#### Сортировка пузырьком (через циклы for):
```python
a = [6, 12, 4, 3, 8]
n = len(a)

for i in range(n - 1):
    for j in range(n - i - 1):
        if a[j] > a[j + 1]:
            # Классический обмен через временную переменную
            aj_old_value = a[j]
            a[j] = a[j + 1]
            a[j + 1] = aj_old_value

print("Отсортированный массив:", a)
```

#### Сортировка пузырьком (через циклы while и множественное присваивание):
```python
a = [6, 12, 4, 3, 8]
n = len(a)

i = 0
while i < (n - 1):
    j = 0
    while j < (n - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]  # Python swap
        j += 1
    i += 1

print("Отсортированный массив:", a)
```
