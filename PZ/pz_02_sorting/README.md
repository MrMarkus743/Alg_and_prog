## Solutions & Theoretical Analysis

### Задача № 1. Сложность вывода текста
```python
def showText(text):
    print(text)

text = 'Hello, World!'
showText(text=text)
```
* **Анализ:** Операция вызова функции и вывод строки фиксированной длины не зависят от размера внешнего массива данных.
* **Итоговая сложность:** $O(1)$ (константная).

---

### Задача № 2. Сложность последовательных циклов
```python
list1 = [10, 15, 20, 25, 500]

for element in list1:
    print(element, end='\t')

for i in range(5):
    print(list1[i])
```
* **Анализ:** В коде присутствуют два последовательных цикла длины $N = 5$. Каждый цикл выполняет $O(N)$ действий.
* **Закон сложения:** $O(N) + O(N) = O(2N) \to O(N)$.
* **Итоговая сложность:** $O(N)$ (линейная).

---

### Задача № 3. Сложность вложенных циклов
```python
list1 = [10, 15, 20, 25, 500]
n = len(list1)

for i in range(n):
    el1 = [list1[i]]
    for j in range(n):
        el2 = [list1[j]]
        if el1 != el2:
            print(el1, '--', el2)
```
* **Анализ:** Внешний цикл выполняется $N$ раз. Внутри него для каждого шага внутренний цикл выполняется $N$ раз.
* **Закон умножения:** $O(N) \times O(N) = O(N^2)$.
* **Итоговая сложность:** $O(N^2)$ (квадратичная).

### Задача № 4. Сортировка выбором (Selection Sort) для `[6, 12, 4, 3, 8]`

Пошаговое описание алгоритма «на месте» (In-Place):
1. **Шаг 1:** Поиск минимума среди индексов `0..4`. Минимум равен `3` (индекс 3). Меняем местами с элементом на индексе 0 (`6`).  
   Состояние массива: `[3 | 12, 4, 6, 8]`.
2. **Шаг 2:** Поиск минимума среди индексов `1..4`. Минимум равен `4` (индекс 2). Меняем местами с элементом на индексе 1 (`12`).  
   Состояние массива: `[3, 4 | 12, 6, 8]`.
3. **Шаг 3:** Поиск минимума среди индексов `2..4`. Минимум равен `6` (индекс 3). Меняем местами с элементом на индексе 2 (`12`).  
   Состояние массива: `[3, 4, 6 | 12, 8]`.
4. **Шаг 4:** Поиск минимума среди индексов `3..4`. Минимум равен `8` (индекс 4). Меняем местами с элементом на индексе 3 (`12`).  
   Состояние массива: `[3, 4, 6, 8 | 12]`.
5. **Итог:** Массив полностью упорядочен: `[3, 4, 6, 8, 12]`. Число сравнений: $4 + 3 + 2 + 1 = 10$.

### Задача № 5. Сортировка пузырьком (Bubble Sort) для `[6, 12, 4, 3, 8]`

Пошаговое описание внешних и внутренних проходов:
* **Проход 1 (диапазон 0..3):**
  - $6 > 12$ — Нет. Массив: `[6, 12, 4, 3, 8]`
  - $12 > 4$ — Да, обмен. Массив: `[6, 4, 12, 3, 8]`
  - $12 > 3$ — Да, обмен. Массив: `[6, 4, 3, 12, 8]`
  - $12 > 8$ — Да, обмен. Массив: `[6, 4, 3, 8, 12]`  
  *(Число 12 встало на свое финальное место)*.
* **Проход 2 (диапазон 0..2):**
  - $6 > 4$ — Да, обмен. Массив: `[4, 6, 3, 8, 12]`
  - $6 > 3$ — Да, обмен. Массив: `[4, 3, 6, 8, 12]`
  - $6 > 8$ — Нет. Массив: `[4, 3, 6, 8, 12]`
* **Проход 3 (диапазон 0..1):**
  - $4 > 3$ — Да, обмен. Массив: `[3, 4, 6, 8, 12]`
  - $4 > 6$ — Нет. Массив: `[3, 4, 6, 8, 12]`
* **Проход 4 (диапазон 0..0):**
  - $3 > 4$ — Нет. Обменов не было, сработал флаг завершения.
* **Итог:** `[3, 4, 6, 8, 12]`.

Функции `selection_sort` и `bubble_sort` протестированы на массивах из 20 и 50 случайных чисел:

### Задача № 9. Поиск в отсортированном массиве из 50 элементов

* **Дано:** Отсортированный массив $L_1$ ($N = 50$). Ищем число `10`.
* **Сравнение алгоритмов:**
  - Линейный поиск: $O(N) \implies$ до 50 операций.
  - Бинарный поиск: $O(\log_2 N) \implies \lceil \log_2 50 \rceil \le 6$ операций.
* **Наиболее эффективное решение:** **Бинарный поиск** ($O(\log N)$). Никакие сортировки применять не нужно, так как массив уже отсортирован.

---

### Задача № 10. Поиск в неотсортированном массиве из 50 элементов

* **Дано:** Неотсортированный массив $L_1$ ($N = 50$). Ищем число `10`.
* **Вариант 1 (Линейный поиск напрямую):**  
  Сложность: $O(N) = 50$ операций.
* **Вариант 2 (Сортировка пузырьком/выбором + Бинарный поиск):**  
  Сложность: $O(N^2) + O(\log N) \approx 1225 + 6 = 1231$ операция.
* **Вывод:** Для **однократного** поиска в неотсортированном массиве эффективнее применить **обычный линейный поиск** ($O(N)$). Предварительная сортировка квадратичными методами создает колоссальный оверхед ($O(N^2)$) и оправдана только в том случае, если после сортировки поиск будет выполняться сотни раз.

### Задача № 11. Оптимальный план выполнения 4 операций

**Дано:** Неотсортированный массив из 50 элементов.  
**Требуемые операции:**
1. Вывести первый элемент.
2. Найти минимальное значение.
3. Найти максимальное значение.
4. Выполнить поиск элемента со значением `10`.

#### Анализ стратегий:
* **Стратегия А (Без предварительной сортировки):**
  1. Вывод первого элемента `arr[0]`: $O(1)$.
  2. Поиск минимума и максимума за один совместный проход (или встроенными `min()` / `max()`): $O(N) + O(N) = 2 \cdot O(N)$.
  3. Линейный поиск числа `10`: $O(N)$.
  * *Суммарная сложность по закону сложения:* $O(1) + O(N) + O(N) + O(N) = O(3N) \to \mathbf{O(N)}$ (линейная, $\approx 150$ базовых операций).

* **Стратегия Б (С предварительной сортировкой):**
  1. Сортировка массива (выбором или пузырьком): $O(N^2) \approx 1225$ операций.
  2. После сортировки минимум — `arr[0]` ($O(1)$), максимум — `arr[-1]` ($O(1)$), поиск числа `10` бинарным поиском ($O(\log N)$).
  * *Суммарная сложность:* $O(N^2) + O(1) + O(1) + O(\log N) \to \mathbf{O(N^2)}$.

#### Оптимальный порядок действий:
Самым эффективным является выполнение операций **без предварительной сортировки** в следующем порядке:
1. Вывести первый элемент массива по индексу `arr[0]` ($O(1)$).
2. За один линейный проход по массиву ($O(N)$) параллельно найти `min`, `max` и проверить наличие элемента `10`.
Итоговая асимптотическая сложность всей программы составит строгие **$O(N)$**.
