## Теоретические сведения

### 1. Хеш-таблица: общие сведения

* **Хеш-таблица (Hash Table)** — структура данных, основанная на массиве и хеш-функции.
* **Хеш-функция (Hash Function)** — функция, получающая на вход строку (или последовательность байтов) и возвращающая число (хеш-код).
* **Требования к хеш-функции:**
  1. *Последовательность (детерминированность):* для одинаковых входных данных возвращается одно и то же число.
  2. *Равномерность:* минимизация совпадений хеш-кодов для разных входных данных.

#### Таблица 1. Сложность основных операций над хеш-таблицей

| Структура данных | Поиск (чтение) | Вставка | Удаление |
| :--- | :---: | :---: | :---: |
| **Массив** | $O(1)$ | $O(n)$ | $O(n)$ |
| **Связный список** | $O(n)$ | $O(1)$ | $O(1)$ |
| **Хеш-таблица (средний случай)** | $O(1)$ | $O(1)$ | $O(1)$ |
| **Хеш-таблица (худший случай)** | $O(n)$ | $O(n)$ | $O(n)$ |

### 2. Коллизии

**Коллизия** — ситуация, при которой несколько разных ключей отображаются на одну и ту же ячейку хеш-таблицы.

#### 2.1. Методы разрешения коллизий
1. **Метод цепочек (Chain Method):** в каждой ячейке массива хранится связный список пар «ключ-значение».
2. **Метод открытой адресации (Linear Probing):** при занятости ячейки выполняется линейный поиск следующей свободной ячейки по порядку. Для удаления заводится специальный логический флаг `deleted`.

#### 2.2. Коэффициент заполнения (Load Factor)
$$\text{Load Factor} = \frac{n}{N}$$
Где $n$ — число элементов в таблице, $N$ — общая емкость массива.  
Если $\text{Load Factor} > 0.7$, таблица расширяется (обычно вдвое) с полным рехешированием всех записей.

---

### 3. Алгоритмы хеширования и соление паролей

* Семейства криптографических хешей: **SHA** (SHA-256, SHA-512) и **MD** (MD5).
* **Соль (Salt)** — случайная строка, добавляемая к паролю перед хешированием для защиты от атак по словарю и радужных таблиц.
  - *Статическая соль:* одна константа на всю базу.
  - *Динамическая соль:* уникальная строка, генерируемая для каждого пароля индивидуально.

### 4. Реализация хеш-таблицы в Python

#### 4.1. Встроенный словарь `dict`:
```python
hash_table = {}
hash_table['Студент 1'] = 4
hash_table['Студент 2'] = 5
print(hash_table.get('Студент 1'))  # 4
```

#### 4.2. На основе двумерного списка:
```python
hash_table = [[] for _ in range(5)]

```
