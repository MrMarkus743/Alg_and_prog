# Practical Work 09: Sets and Hashable Objects in Python

## Overview

Практическая работа посвящена исследованию встроенных структур данных «Множество» (`set`) и «Неизменяемое множество» (`frozenset`), анализу их внутреннего устройства на базе хеш-таблиц, реализации теоретико-множественных операций кругов Эйлера и применению множеств для решения оптимизационных задач дедупликации и Two-Sum за линейное время $O(n)$.

## Solutions & Theoretical Analysis

### 1. Архитектура `set` в Python и оценка быстродействия

Множество в CPython реализовано как разреженная хеш-таблица, хранящая только ключи без связанных значений:

| Операция | Синтаксис | Средняя сложность | Худшая сложность | Принцип работы |
| :--- | :--- | :---: | :---: | :--- |
| **Добавление** | `s.add(x)` | $O(1)$ | $O(n)$ | Хеширование объекта и запись в свободную ячейку |
| **Удаление** | `s.remove(x)` / `discard(x)` | $O(1)$ | $O(n)$ | Поиск по хешу и установка маркера Dummy |
| **Проверка вхождения** | `x in s` | $O(1)$ | $O(n)$ | Мгновенный переход по хешу вместо перебора списка |
| **Пересечение** | `s1 & s2` | $O(\min(n_1, n_2))$ | $O(n_1 \times n_2)$ | Итерация по меньшему множеству с проверкой в большем |
| **Объединение** | `s1 \| s2` | $O(n_1 + n_2)$ | $O(n_1 + n_2)$ | Копирование первого и добавление элементов второго |

#### Различие между `set` и `frozenset`:
* `set` является изменяемым (*mutable*) и не имеет метода `__hash__()`. Попытка положить `set` в качестве ключа словаря или элемента другого множества вызовет ошибку `TypeError: unhashable type: 'set'`.
* `frozenset` неизменяем (*immutable*), его хеш-сумма рассчитывается один раз при создании, что позволяет безопасно использовать его в роли ключа словаря.

### 2. Разбор решений практических задач

#### Задача № 1. Базовые операции и хэшируемость
Продемонстрировано удаление дубликатов из исходного списка целых чисел, безопасное удаление без исключения через `discard()`, а также использование `frozenset` в качестве ключа ассоциативного массива.

#### Задача № 2. Теоретико-множественные операции (Круги Эйлера)
Реализован расчет четырех базовых отношений:
* Объединение ($A \cup B$): `set_a | set_b`
* Пересечение ($A \cap B$): `set_a & set_b`
* Разность ($A \setminus B$): `set_a - set_b`
* Симметрическая разность ($(A \cup B) \setminus (A \cap B)$): `set_a ^ set_b`

#### Задача № 3. Анализ символьного состава строк
Выполнен расчет пересечения буквенного состава двух слов для выявления анаграмм и общих фонем за $O(L_1 + L_2)$ вместо квадратичного поиска вложенными циклами.

#### Задача № 4. Задача Two-Sum ($A + B = X$) за линейное время $O(n)$
* **Проблема наивного метода:** попарный перебор двух элементов списка через два вложенных цикла требует времени $O(n^2)$.
* **Оптимальный алгоритм через `set`:** при обходе массива для текущего числа $y$ вычисляется требуемое второе слагаемое $x = \text{target} - y$. Проверка `x in seen` выполняется за $O(1)$. В результате весь массив обрабатывается строго за один проход $O(n)$ при расходе памяти $O(n)$.

#### Задача № 5. Дедупликация потока данных
Нахождение всех повторяющихся элементов выполняется с разделением на два множества: `seen` (уже встреченные) и `duplicates` (встреченные повторно), что гарантирует линейное время $O(n)$ и исключает многократную запись одного и того же дубликата.
