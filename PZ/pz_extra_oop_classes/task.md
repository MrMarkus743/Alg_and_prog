## Теоретические сведения

### 1. Объектно-ориентированное программирование

#### 1.1. Класс. Объект
Типы объектов в Python делятся на две категории:
* встроенные типы (`int`, `float`, `str`, `list` и т.д.);
* пользовательские (собственные) типы, создаваемые программистом с помощью классов.

* **Класс (Class)** — некоторая абстрактная сущность, служащая шаблоном для создания объектов. Абстрактное описание множества однородных объектов, имеющих одинаковые атрибуты, операции и отношения.
* **Объект (Object)** — экземпляр соответствующего класса, его конкретное воплощение.

#### 1.2. Наследование. Инкапсуляция. Полиморфизм
* **Наследование (Inheritance)** — механизм, посредством которого класс-наследник наделяется свойствами и поведением класса-родителя.
* **Инкапсуляция** — сокрытие внутренней структуры объекта и ограничение прямого доступа к его переменным извне.
* **Полиморфизм** — способность методов с одинаковыми именами демонстрировать различное поведение в зависимости от типа объекта, к которому они применяются.

### 2. Определение класса и объектов класса в Python

Для объявления класса используется ключевое слово `class`:

```python
class Student:
    pass

std1 = Student()
std2 = Student()
std3 = Student()
```

### 3. Атрибуты и методы

#### 3.1. Атрибуты класса
Атрибуты представляют собой переменные, описывающие состояние. Атрибуты класса являются общими для всех объектов:

```python
class Student:
    name = '...'
    age = 0
    course = 0

std1 = Student()
std1.name = 'Jack'
std1.course = 1
```

#### 3.2. Методы класса
Методы — это функции внутри класса. Первым параметром каждого метода объекта обязательно указывается `self`, ссылающийся на текущий экземпляр:

```python
class Student:
    def start_studying(self):
        print('Студент приступил к занятиям')

    def finish_studying(self):
        print('У студента закончились занятия')

    def study(self, student_name, student_course=-1):
        self.name = student_name
        self.course = student_course
        print(f'Студент: {self.name}; Курс: {self.course}')
        self.start_studying()
        self.finish_studying()

std1 = Student()
std1.study(student_name='Jack')
```

#### 3.3. Атрибуты объекта и конструктор `__init__`
Инициализация атрибутов экземпляра происходит в методе `__init__()`:

```python
class Student:
    def __init__(self, name, age, course):
        self.name = name
        self.age = age
        self.course = course
        print(f'Создан объект: {self.name}, {self.age}, {self.course}')

std1 = Student('Jack', 20, 1)
```

#### 3.4. Подчеркивания в именах Python
1. `_name` (*single leading underscore*) — соглашение об индикаторе внутреннего использования.
2. `name_` (*single trailing underscore*) — соглашение для избежания конфликта с ключевыми словами Python (например, `list_ = [1, 2]`).
3. `__name` (*double leading underscore*) — включает механизм искажения имен (*name mangling*), превращая имя в `_ClassName__name`.
4. `__name__` (*double leading and trailing underscore*) — системные «магические» методы языка (`__init__`, `__str__`).

### 4. Инкапсуляция: приватные атрибуты, методы-свойства

#### 4.1. Приватные атрибуты
При использовании двух подчеркиваний прямой доступ к полю блокируется:

```python
class Student:
    def __init__(self, name, age, course):
        self.name = name
        self.__age = age        # Приватный атрибут
        self.__course = course  # Приватный атрибут

std1 = Student('Jack', 20, 1)
# print(std1.__age)  # Вызовет AttributeError!
print(std1._Student__age)  # Доступ возможен только через искаженное имя: 20
```

#### 4.2. Методы-свойства (Геттер, Сеттер, Делитер)
```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.__age = age

    def get_age(self):
        return self.__age

    def set_age(self, value):
        if value > 0:
            self.__age = value
```

#### 4.3. Аннотации свойств и декоратор `@property`
Современный синтаксис Python позволяет объявлять методы доступа через декоратор `@property`:

```python
class Student:
    def __init__(self, name, age, course):
        self.name = name
        self.__age = age
        self.__course = course

    @property
    def age(self):
        return self.__age

    @age.setter
    def age(self, value):
        self.__age = value

    @age.deleter
    def age(self):
        del self.__age

std1 = Student('Jack', 20, 1)
print(std1.age)   # Вызов геттера: 20
std1.age = 40     # Вызов сеттера
del std1.age      # Вызов делитера
```

### 5. Наследование

#### 5.1. Простое наследование
```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(User):
    pass

std1 = Student('Jack', 20)
print(std1.name)  # Унаследовано от User
```

#### 5.2. Множественное наследование
```python
class Admin:
    def __init__(self):
        self.admin_password = 'admin11'

class Guest:
    def __init__(self):
        self.guest_password = 'guest11'

class Teacher(Admin, Guest):
    pass
```

#### 5.3. Переопределение функционала и функция `super()`
Функция `super()` делегирует вызовы конструктора и методов базовому классу:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def print_atr(self):
        print(f'name: {self.name}, age: {self.age}')

class Student(User):
    def __init__(self, name, age, course):
        super().__init__(name, age)  # Вызов конструктора родителя
        self.course = course

    def print_atr(self):
        super().print_atr()
        print(f'course: {self.course}')
```
