# Practical Work Extra: OOP and Classes in Python

## Overview

Дополнительная практическая работа посвящена закреплению принципов объектно-ориентированного программирования (ООП) на языке Python: наследованию, инкапсуляции через приватные атрибуты и декоратор `@property`, переопределению конструкторов через `super()`, наследованию стандартных типов (`list`), а также разработке дискретных симуляций бизнес-систем («Пекарня» и «Ферма»).

---

## Solutions & Theoretical Analysis

### Задача № 1. Иерархия пользователей образовательной платформы

* **Базовый класс `User`:**
  - Генерация автоинкрементного идентификатора формата `U001`, `U002` с использованием переменной класса `_user_counter`.
  - Приватные поля логина и пароля с управлением доступом через декораторы `@property` и `@setter`.
  - Валидация пароля на длину не менее 7 символов и одновременное наличие цифр, строчных и заглавных букв.
  - Проверка уникальности логина с сохранением в классовый реестр `_existing_logins`.
* **Класс `Student(User)`:**
  - Наследует базовые атрибуты через `super().__init__(login, password)`.
  - Переопределяет идентификатор формата `S001`, добавляет поля `name` и `course`.
* **Класс `Teacher(User)`:**
  - Генерирует идентификатор формата `T001`, хранит атрибут педагогического стажа `experience`.
  - Содержит методы `add_student()` и `remove_student()` для управления списком прикрепленных студентов.

### Задача № 2. Класс `MyList` (расширение `list`)

1. `print_info()`: форматированный вывод длины коллекции.
2. `drop_value(value)`: циклическое удаление всех элементов, совпадающих с `value`, без создания нового объекта списка.
3. `add_indeces()`: перестроение списка со вставкой маркеров `'id-i'` перед каждым значением.
4. `append(value)`: переопределение стандартного метода `append()` родительского класса `list` с автоматическим добавлением маркера `'id-k'`.

### Задача № 3. Симуляция «Пекарня»

Модель построена на взаимодействии четырех ролей:
* `Manager`: проводит аудит выручки и контролирует складские остатки;
* `Baker`: производит продукцию (`хлеб`, `булочка`, `готовая еда`, `напитки`);
* `Cashier`: проводит операцию продажи, принимает оплату и передает товар клиенту;
* `Customer`: хранит бюджет кошелька и корзину приобретенных позиций.

---

### Задача № 4. Симуляция «Ферма»

Реализована экономическая консольная пошаговая система:
* **Культуры (`Crop`):** фазы вегетации (1 — саженец, 2 — рост, 3 — созревание). Сбор урожая приносит прибыль.
* **Животные (`Animal`):** требуют обязательного кормления для перехода между стадиями взросления и регулярного сбора продукции.
* **Ферма (`Farm`):** смена циклов «День/Ночь», покупка семян и животных, расширение земельных наделов и загонов при накоплении монет. Конечная цель симуляции — расширение инфраструктуры и достижение оборота в 100 000 монет.
