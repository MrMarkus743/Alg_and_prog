# Practical Work 11: AVL Tree and Traversal Algorithms

## Overview

Практическая работа посвящена исследованию самобалансирующихся бинарных деревьев поиска (Адельсон-Вельский, Ландис). Реализован полноценный класс АВЛ-дерева с автоматическим пересчетом показателей баланса, поддержкой малых (LL, RR) и больших (LR, RL) поворотов при вставке и удалении, а также алгоритмами обхода в глубину (In-order, Pre-order, Post-order) и ширину (BFS).

## Solutions & Theoretical Analysis

### 1. Сравнительный анализ: BST vs AVL Tree

| Критерий | Обычное BST | АВЛ-дерево |
| :--- | :---: | :---: |
| **Высота в среднем случае** | $O(\log n)$ | $O(\log n)$ |
| **Высота в худшем случае (отсортированный ввод)** | $O(n)$ | $\approx 1.44 \log_2 n$ |
| **Поиск (`Search`)** | $O(\log n)$ сред. / $O(n)$ худш. | Строго $O(\log n)$ |
| **Вставка / Удаление** | $O(\log n)$ сред. / $O(n)$ худш. | Строго $O(\log n)$ |
| **Дополнительная память на узел** | Нет | Поле высоты или баланса |

### 2. Разбор практических задач (Вариант № 1)

#### Исходный набор данных:
`27, 34, 17, 20, 10, 5, 15, 11, 14, 12, 16, 40, 33, 37`

#### Повороты в процессе вставки:
* При добавлении `5`: в поддереве корня `17` возникает нарушение баланса (LL), выполняется правый поворот вокруг `10`.
* При добавлении `12` и `16`: разрешаются зигзагообразные перекосы цепочек через большие повороты (LR / RL).
* Итоговая высота дерева для 14 узлов не превышает 4 уровней.

#### Результаты алгоритмов обхода:
* **Центрированный (In-order, LNR):** `[5, 10, 11, 12, 14, 15, 16, 17, 20, 27, 33, 34, 37, 40]` — все ключи упорядочены по строгому возрастанию.
* **Прямой (Pre-order, NLR):** корень посещается первым, затем рекурсивно левая и правая ветви.
* **Обратный (Post-order, LRN):** узел посещается после завершения обработки всех его потомков.
* **Обход в ширину (BFS):** посещение узлов уровень за уровнем через очередь `deque`.

### 3. Балансировка после удаления (Случаи 1a, 1b, 2a, 2b)

* **Случай 1a (L-поворот):** правый сын имеет неотрицательный баланс ($\ge 0$). Выполняется одинарный поворот налево.
* **Случай 1b (RL-поворот):** правый сын имеет отрицательный баланс ($< 0$). Выполняется двойной поворот (сначала направо, затем налево).
* **Случай 2a (R-поворот):** левый сын имеет неположительный баланс ($\le 0$). Выполняется одинарный поворот направо.
* **Случай 2b (LR-поворот):** левый сын имеет положительный баланс ($> 0$). Выполняется двойной поворот (сначала налево, затем направо).
