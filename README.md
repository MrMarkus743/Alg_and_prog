Программная реализация фундаментальных структур данных и алгоритмов на чистом Python без использования сторонних библиотек, асимптотический анализ вычислительной сложности ($O$-нотация) и подготовка к курсовому проекту.

## О дисциплине

Курс посвящен проектированию эффективных программных систем, исследованию низкоуровневых механизмов управления памятью, оценке временной и пространственной сложности алгоритмов, а также изучению ключевых структур хранения информации:

* **Базовые алгоритмы поиска и сортировки:** линейный и бинарный поиск, квадратичные методы ($O(n^2)$), алгоритмы парадигмы «разделяй и властвуй» ($O(n \log n)$), специализированные некомпаративные линейные сортировки ($O(n + k)$).
* **Линейные и динамические структуры данных:** организация стеков вызовов (LIFO), очереди (FIFO) и двусторонние очереди (Deque), списковые структуры на узлах (однонаправленные, двунаправленные, циклические).
* **Хеширование и ассоциативные контейнеры:** проектирование собственных хеш-таблиц, методы разрешения коллизий (открытая адресация, метод цепочек), расчет коэффициента заполнения (`Load Factor`), криптографическое соление паролей и теоретико-множественные операции.
* **Иерархические структуры и деревья поиска:** бинарные деревья поиска (BST), самобалансирующиеся АВЛ-деревья, сильноветвистые B-деревья (2-3 и 2-3-4 порядков), эквивалентные им левосторонние (LLRB) и классические красно-черные деревья (RB-Tree), обходы в глубину (DFS) и ширину (BFS).
* **Культура разработки:** строгое соблюдение PEP 8, объектно-ориентированное программирование (инкапсуляция, наследование, полиморфизм), обработка граничных условий (`edge cases`) и версионирование по стандарту Conventional Commits.

## Assignment Workflow & Engineering Standards

Для каждого практического модуля в каталоге `PZ/` поддерживается единый набор файлов и регламент:

1. **Постановка задачи (`task.md`):** Полные теоретические сведения, математические инварианты структур данных, схемы преобразований и варианты практических заданий.
2. **Чистая реализация (`solution.py`):**
   - Соблюдение стандартов стиля **PEP 8** (читаемые имена в `snake_case`, стандартные отступы в 4 пробела, отсутствие «магических» конструкций).
   - Отсутствие вводных шапок с темами и декоративных разделителей для сохранения чистоты кода.
   - Использование ручных итераций и прямых вызовов методов контейнеров для демонстрации работы алгоритмов.
   - Корректная обработка граничных условий (`edge cases`): пустые наборы, единичные элементы, уже упорядоченные последовательности и дубликаты.
3. **Отчетность и анализ (`README.md`):** Развернутый теоретический разбор, сравнительные таблицы алгоритмической сложности ($O$-нотация), схемы вызовов и текстовая визуализация структур данных.
4. **Контроль версий:** Фиксация выполненных этапов атомарными коммитами по стандарту **Conventional Commits** (`feat:`, `docs:`, `fix:`, `refactor:`).

## Getting Started

### 1. Клонирование репозитория
```bash
git clone https://github.com/MrMarkus743/Alg_and_prog
cd Alg_and_prog
```

### 2. Настройка виртуального окружения
* **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
* **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Запуск практических работ
Каждая практика запускается из корневого каталога репозитория:
```powershell
python PZ/pz_01_search/solution.py
python PZ/pz_02_sorting/solution.py
```
