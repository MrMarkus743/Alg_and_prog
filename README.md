## О дисциплине

Курс посвящен проектированию эффективных программных решений, глубокому исследованию структур данных и базовых алгоритмических паттернов обработки информации:

* **Алгоритмы поиска и базовой сортировки:** линейный и бинарный поиск, квадратичные методы ($O(n^2)$), эффективные алгоритмы «разделяй и властвуй» ($O(n \log n)$), линейные сортировки подсчетом ($O(n + k)$).
* **Базовые и динамические структуры данных:** организация стеков вызовов, очереди (FIFO) и деки, однонаправленные, двунаправленные и циклические связные списки.
* **Хеширование и словари:** построение собственных хеш-таблиц, методы разрешения коллизий (цепочки, открытая адресация), динамический контроль коэффициента заполнения (`Load Factor`).
* **Древовидные структуры:** графы, бинарные деревья поиска (BST) и самобалансирующиеся АВЛ-деревья с вращениями (LL, RR, LR, RL), алгоритмы обходов в глубину (DFS) и ширину (BFS).
* **Культура разработки:** парадигма ООП, строгая типизация (`type hinting`), покрытие граничных случаев (`edge cases`) и асимптотический анализ по времени и памяти.

## Assignment Workflow & Engineering Standards

Для каждого практического занятия в каталоге `PZ/` создается отдельная папка по единому шаблону `pz_<номер>_<тема>` (например, `pz_01_search`, `pz_02_sorting`), жизненный цикл которой включает:

1. **Requirements Modeling (`task.md`):** Описание условий, теоретический базис и контрольные примеры, перенесенные в чистый формат Markdown.
2. **Environment Isolation (`venv`):** Запуск кода в изолированном виртуальном окружении без засорения системного интерпретатора.
3. **Clean & Resilient Code (`solution.py`):**
   - Соблюдение стандартов стиля **PEP 8** (читаемые имена в `snake_case`, единые отступы, структурированные docstrings).
   - Обязательная строгая аннотация типов (`type hinting`).
   - Изолированная валидация краевых случаев (`edge cases`): пустые списки, поиск дубликатов, значения на границах массивов, единичные элементы.
   - Теоретическая и практическая оценка асимптотической сложности алгоритма ($O$-нотация).
4. **Report & Documentation (`README.md`):** Развернутые ответы на теоретические вопросы методички, логи работы скриптов (`execution logs`) и аналитические выводы.
5. **Version Control:** Фиксация выполненных этапов по стандарту **Conventional Commits** (`feat:`, `docs:`, `fix:`, `refactor:`).

## Getting Started

### 1. Клонирование репозитория
```bash
git clone [https://github.com/](https://github.com/)<ваш-аккаунт>/Alg_and_prog.git
cd Alg_and_prog
```

### 2. Настройка виртуального окружения
* **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
* **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Запуск практических работ
Каждая практика запускается из корневого каталога репозитория:
```powershell
python PZ/pz_01_search/solution.py
python PZ/pz_02_sorting/solution.py
```
